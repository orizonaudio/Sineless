# Brand

The Orizon logo, as the UI shows it. Its image files (`*.svg`) are not under the GPL: their terms are in
[LICENSES/LicenseRef-Orizon-Brand.txt](../../../LICENSES/LicenseRef-Orizon-Brand.txt), and
[TRADEMARKS.md](../../../TRADEMARKS.md) says what the names allow.

Builds of modified versions leave them out: configure with `-DSINELESS_BRANDING=OFF`, and the
page takes the neutral files in `ui/src/unbranded/` instead.
